# Source of `manoir`

The opening of Johann Sebastian Bach's Toccata in D minor, BWV 565 (public domain), set down note by note in compose.py from memory of the piece, with a running figure, chords and a thunderclap written for the game. No third-party transcription or MIDI file is used.

`python3 compose.py` rewrites `source.mid`; `npm run audio -- all spec.json` renders it (docs/en/AUDIO.md).
