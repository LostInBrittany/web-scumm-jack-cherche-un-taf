# Source of `fin`

An original jingle written for the game in compose.py; its first notes quote the call of Bach's Toccata in D minor (public domain), turned into D major.

`python3 compose.py` rewrites `source.mid`; `npm run audio -- all spec.json` renders it (docs/en/AUDIO.md).
