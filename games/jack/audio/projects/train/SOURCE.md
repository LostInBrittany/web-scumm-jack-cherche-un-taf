# Source of `train`

Edvard Grieg's In the Hall of the Mountain King, from Peer Gynt (1875, public domain), set down note by note in compose.py, with the harmony, the bass, the drums and the form (no accelerando) written for the game. No third-party transcription or MIDI file is used.

`python3 compose.py` rewrites `source.mid`; `npm run audio -- all spec.json` renders it (docs/en/AUDIO.md).
