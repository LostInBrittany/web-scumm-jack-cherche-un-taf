# Source of this track

- Work: Pyotr Ilyich Tchaikovsky, *Swan Lake*, Op. 20 (1876): the oboe theme. Public domain.
- `source.mid`: written by `compose.py` in this folder (the melody set down note by note, the harmony, harp, strings
  and bass written for the project). No third-party transcription or recording was used.
- `spec.json` and the renders (`games/demo/audio/music/swan_theme.mp3`, `swan-theme-stems/`): **CC BY 4.0**,
  attribution "Wano", like the rest of the sample game's sound. A game may be sold with it.
