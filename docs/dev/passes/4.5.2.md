# Passes, 4.5.2

4.5.2 adds no pass (`passesFor('4.5.2')` equals 4.5.1's, 22). The twenty-two stay open and are made on the 4.5.2
candidate; none was made for 4.5.2 and none has passed on an earlier release, so none is carried. What 4.5.2 changes
touches some of them: `archive-human-install` follows the README's install line, now `quest-n-click-4.5.2.tgz`, whose
package is `@quest-n-click/engine` (a project of 4.5.1 moves with `npx quest-n-click migrate`); `studio-hosted` and
`studio-assets-hosted` deploy a worker whose build hook installs the hashed `requirements.txt` (`--require-hashes
--only-binary=:all:`), the lock gone; `docs-beginner-reader` reads the wiki with the scoped names and the website's
links (the demo and the latest documentation are on `quest-n-click.cleverapps.io`, GitHub Pages abandoned). The game,
its saves and the Bridge's protocol are otherwise unchanged. The packages on npm (staged by release.yml,
approved by an owner) are not a pass: `npm view @quest-n-click/engine version` answers once they are approved.
`npm run field:init -- --release=4.5.2 --candidate=<the run the tag names>` writes the twenty-two reports;
`npm run field:report` writes the table below.
