# Passes, 4.2.2 "Playable Workshop" (the Studio Server, experimental)

4.2.2 adds the playable workshop (D40: nothing a game or a player uses changed). Its two people's passes are new:
`studio-preview` (on a hosted Studio, people play the shared revision without a dev server, carry a save across
revisions and answer its question, read the health chip and a bisection, undo their own work while another edits,
publish a build and open `/play/<n>/`) and `studio-assets-hosted` (Prepare assets on the processing worker, from the
head's art and sounds, its set played in the Play tab). Both come after `studio-hosted`. Their issues are opened with
the release (label `field-pass`). 4.2.1's `studio-hosted` (#149) and `studio-collab` (#150) and 4.2.0's thirteen
(#75–#87) stay open: they are made on the 4.2.2 candidate, or carried to it once a surface declares an exclusion of
the version with its test (D38).
`npm run field:init -- --release=4.2.2 --candidate=<the run the tag names>` writes the seventeen reports;
`npm run field:report` writes the table below.
