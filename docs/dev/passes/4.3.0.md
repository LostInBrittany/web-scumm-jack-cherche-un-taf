# Passes, 4.3.0 ("Hero Choice")

4.3.0 adds no pass (`passesFor('4.3.0')` equals 4.2.5's). The nineteen of 4.2.5 stay open and are made on the 4.3.0
candidate; none has passed yet, so none is carried. Several surfaces they read changed in 4.3.0: the player's interface
font (Galmuri11 by default), the verb keys and their settings row, the hero choice's portrait cards (the phone, Safari,
Firefox and playtester passes see them in the demo's interface); the README's install section now names
`quest-n-click-4.3.0.tgz` and `npx quest-n-click migrate` (`archive-human-install`); the release ships no `web-scumm…`
archive or command any more, and a hosted Studio's engine upgrade renames a game's former imports first (the six
Studio passes). The nineteen: 4.2.3's `studio-mcp-remote` (#196) and `studio-oidc-generic` (#197), 4.2.2's
`studio-preview` (#166) and `studio-assets-hosted` (#167), 4.2.1's `studio-hosted` (#149) and `studio-collab` (#150),
and 4.2.0's thirteen (#75–#87).
`npm run field:init -- --release=4.3.0 --candidate=<the run the tag names>` writes the nineteen reports;
`npm run field:report` writes the table below.
