# Passes, 4.4.0 ("Author's Desk")

4.4.0 adds two passes (`passesFor('4.4.0')` has 21): `heroes-two-languages`, the example `games/heroes` on a real
phone in English and French (each hero's card, name, lines and voice, a save resumed), and `studio-hero-matrix`, the
Studio's hero × language matrix read by an author on their own game (what it shows, what is missing, what it should
say). The nineteen of 4.3.1 stay open, made on the 4.4.0 candidate; none has passed yet. Surfaces they read that
changed: the phone's right-hand column on a short landscape screen (`phone-both-renderers`, `safari-ios-offline-update`),
a hotspot's single tap and the map's shared pins (the demo is unchanged; a game that uses them), French clips now
shipped (`voices-listening`), and on a hosted Studio the preview's lane and the diff's captures (local only:
`studio-preview` reads the hosted part).
`npm run field:init -- --release=4.4.0 --candidate=<the run the tag names>` writes the twenty-one reports;
`npm run field:report` writes the table below.
