# Passes, 4.2.1 "Shared Floor" (the Studio Server, experimental)

4.2.1 adds the Studio Server (D40: nothing a game or a player uses changed). Its two people's passes are new:
`studio-hosted` (a real deployment by the guide, a real Safari on macOS and iOS, with the game's frame both on two
names of one domain, as the guide recommends, and on two `*.cleverapps.io` names, two sites, plan §6.1) and
`studio-collab` (three people, a cut, a redeploy). Their issues are opened with the release (label `field-pass`). The
thirteen passes of 4.2.0 (#75–#87) stay open: they are made on the 4.2.1 candidate, or carried to it once a surface
declares an exclusion of the version with its test (D38: as the surfaces stand, `field:carry` refuses a 4.2.0 pass for
4.2.1).
`npm run field:init -- --release=4.2.1 --candidate=<the run the tag names>` writes the fifteen reports;
`npm run field:report` writes the table below.
